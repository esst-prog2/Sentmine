# Surface brief: promo page (docs/index.html)

Scope: one static page for GitHub Pages, plain HTML and CSS plus a little JavaScript; visitor mode Persuade. Audience: students reading English course books. Action: install (command and GitHub link in the first viewport). Proof: six real screenshots (docs/img), measured numbers linked to their sources; nothing invented, no author name, no empty video or slides slots. Content: designs/promo-page.md, sections 1-9.

## Direction contract

THESIS: The page is sentmine at work, not a page about an app: the reader sees the real book page, the word in yellow and its card before reading any claim. It refuses the split hero over a row of feature cards.

OWN-WORLD: sentmine's own interface: paper ground #f6f5f1, white panels with #d9d6cd hairlines, ink #1f2328, action blue #1a5fd0, picked-word yellow #ffe27a, dotted blue underline for words that come back; system UI for interface text, Georgia for the book.

STORY: The visitor sees a word clicked on a real page become a card, follows that one card through meaning, cloze, Anki and its return in a later chapter, believes it because every image is a real run and every number has a source, and installs it.

FIRST VIEWPORT: The app header (sentmine; How it works, Comes back, Try it; GitHub and a blue Install). Under it the status line carries the headline "Read the real page. Click a word. It's an Anki card." at display size with one line beneath. Below, the cropped book page with "simultaneously" in yellow on the left, its card in the cards panel on the right. Install is the primary action, top right and repeated in Try it.

FORM: "The page is the reader", 1 on my ordered list of 7, dealt and locked by the user; signature interaction: one card carried through the five steps, the panel staying in view while the steps scroll past (raised from the origami sequence: one continuous object, never five tiles). seed:3c8b71f11ef89147
